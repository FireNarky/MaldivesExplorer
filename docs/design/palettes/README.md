# Maldives Explorer colour palettes

Six directions for the customer-facing site, for team review. Every palette uses the same token names as the site's design system, so the chosen one drops into `globals.css`. All 14 contrast checks pass WCAG AA in every palette (ratios in each `.json`).

## Rules every palette follows
- One accent button per view, with dark ink text on it (white on the accent fails contrast).
- Links and primary buttons use the darker "Lagoon ink", never the bright lagoon.
- Lagoon is decoration only.
- Status words always accompany colour.
